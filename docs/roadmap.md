# Roadmap

Target v0.1: business evidence and continuous verification tools for AI agents. This 0.1.0a1 extraction preview provides installable tools, an English agent guide, synthetic tests and a standalone demonstration.

Remaining v0.1 milestones:
- M1: thin execution entry and a scoped source registry with explicit access, applicability and freshness. Analysis brief structural checks exist; automated preflight does not.
- M2: a public code/data/requirements conflict example including deployment and configuration differences.
- M3: explicit source dependencies and affected-claim revalidation, preserving prior versions.
- M4: same-model, same-source comparisons against an unassisted agent, plus independent transfer cases. Measure errors, omissions, time and rework rather than model participation percentages.
- M5: independent installation, host integration, public content review, license selection and external-user acceptance. Packaging can precede the full analysis loop.

The included demo proves bookkeeping and validation only; it is not an end-to-end business analysis benchmark. Future scope may change based on evidence. Keep model reasoning flexible, protocols explicit, and inputs scoped. Do not rebuild generic RAG, BI or observability platforms without measured need.
